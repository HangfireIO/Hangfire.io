This patch release contains an improved cluster detection logic for Azure Managed Redis service with OSS policy enabled, which wrongly reports Redis mode as "Standalone", instead of "Cluster", leading to "Endpoint serving hashslot is not reachable" errors. The update contains other means for cluster detection and makes it possible to connect to Azure Managed Redis OSS clusters.

#### Hangfire.Pro.Redis

* **Changed** – Update StackExchange.Redis binaries to 1.2.7-build-00094 with Azure Managed Redis OSS supported.
* **Fixed** – "Endpoint serving hashslot is not reachable" error when connecting to Azure Managed Redis OSS cluster.
